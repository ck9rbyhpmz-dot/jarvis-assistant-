JARVIS iPhone Starter

This is a free progressive web app starter, not a native iOS .ipa app. It includes a futuristic dashboard, basic typed commands, device speech synthesis, a one-minute timer, and simple website-opening commands. It is not connected to a full AI model yet.

To install on iPhone:
1. Upload all four app files (index.html, manifest.webmanifest, sw.js, jarvis-icon.svg) to an HTTPS static host.
2. Open the hosted URL in Safari.
3. Tap Share > Add to Home Screen > Add.

GitHub Pages free hosting uses a public repository, so the source code is visible to anyone. Do not put passwords, API keys, or private information in the repository.

Limitations: iOS does not allow ordinary web apps to control the whole phone. Microphone recognition support varies by browser/iOS version. The voice uses a suitable English voice available on the device. The app's basic features do not need an API key; connecting a full AI model later may require a paid service.
